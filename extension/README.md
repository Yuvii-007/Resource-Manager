# Resource Manager — Browser Extension (Manifest V3)

Capture any webpage, highlighted text, category, and multi-label tags with one click.

## How to Install in Chrome / Brave / Edge

1. Open your browser and navigate to `chrome://extensions/` (or `edge://extensions/`, `brave://extensions/`).
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select this `extension` directory.
5. The teal diamond icon will appear in your browser toolbar!

## Features

- **Instant Capture**: Automatically reads the active tab's title and URL.
- **Smart Notes**: Automatically fills notes with any text you highlighted on the page.
- **Category Autocomplete**: Fetches your existing categories and tags live from the vault.
- **Right-Click Context Menu**: Right-click anywhere on any page to "Save to Resource Manager Vault".
- **Keyboard Shortcut**: Press `Alt + Shift + S` to quickly save the current page.
- **Offline Resilient**: If your local server is offline, bookmarks are queued safely in browser storage and synced automatically once connected.
